# External Integrations

**Analysis Date:** 2026-09-20

## APIs & External Services

**Database (hosted Postgres):**

- Supabase PostgreSQL — persistence for templates, redirects, plates, analytics.
  - SDK/Client: `pg` `^8.23.0` + `drizzle-orm` `^0.45.2` via `packages/database/src/client.ts`. **Do not use `@supabase/supabase-js`** — it is only declared in root `package.json` and is not imported.
  - Auth: connection string `DATABASE_URL`. `getDatabaseUrl()` in `packages/database/src/client.ts` rewrites `db.<projectRef>.supabase.co:5432` to session pooler `aws-0-sa-east-1.pooler.supabase.com:6543` (user becomes `user.projectRef` when needed). Non-localhost connections set `ssl: { rejectUnauthorized: false }`.
  - Schema: `packages/database/src/schema/index.ts`. Seed: `seedDefaultTemplates()` in `packages/database/src/client.ts`, triggered when `DATABASE_URL` is set (`apps/plateflow-api/src/infrastructure/http/app.ts`).

**Payments (Pix, local — no PSP):**

- Banco Central Pix BR Code (EMV) — generated in-process by `generatePixBrCode()` in `apps/plateflow-api/src/infrastructure/services/PixCodeService.ts`. Served as HTML + QR on `/r/:slug` when `redirect.type === 'pix'` (`apps/plateflow-api/src/infrastructure/http/routes/publicRedirectRoutes.ts`).
  - SDK/Client: none (manual EMV + CRC16).
  - Auth: Not applicable. No Pix API key, no PSP webhook.

**Messaging / social deep links (outgoing HTTP redirects):**

- WhatsApp — `307` redirect to `https://wa.me/{phone}?text=` (`publicRedirectRoutes.ts`). Phone/message from `DynamicRedirectMetadata` in `packages/types/src/index.ts`.
  - SDK/Client: none.
  - Auth: Not applicable.
- Instagram — `307` redirect to `https://instagram.com/{handle}` when `redirect.type === 'social'` (`publicRedirectRoutes.ts`).
  - SDK/Client: none.
  - Auth: Not applicable.

**Contact cards:**

- vCard 3.0 — generated by `generateVCardString()` in `apps/plateflow-api/src/infrastructure/services/VCardService.ts`. HTML preview + `?download=1` `.vcf` download on `/r/:slug`.
  - SDK/Client: none.

**QR / batch graphics (client + server libraries, not SaaS):**

- `qrcode` — server Pix QR (`publicRedirectRoutes.ts`) and client plate QR (`apps/plateflow-app/src/services/imageComposerService.ts`).
- `jszip` — ZIP of composed plate images (`imageComposerService.ts`).
- Canvas 2D — stamp QR onto template backgrounds in the browser (`imageComposerService.ts`). Template `background_url` values are stored as data URIs in Postgres (`packages/database/src/client.ts` seed, `templates` table).

**Browser hardware APIs (not vendor SDKs):**

- Web NFC (`NDEFReader`) — write short URL `/r/{slug}` to tags in `apps/plateflow-app/src/components/NfcAssistantModal.tsx`. Chrome/Android only; no NFC cloud service.
- PWA install — `beforeinstallprompt` in `apps/plateflow-app/src/hooks/usePWAInstall.ts`; manifest `apps/plateflow-app/public/manifest.json`.

**CDN / fonts:**

- Google Fonts — Plus Jakarta Sans + JetBrains Mono in `apps/plateflow-app/index.html` (`fonts.googleapis.com` / `fonts.gstatic.com`).
- Tailwind CDN (`cdn.tailwindcss.com`) — only on HTML error/Pix/vCard pages in `publicRedirectRoutes.ts`. Do not use the CDN in the Vite app; the app uses `@tailwindcss/vite`.

**Declared but unused:**

- `@google/genai` in root `package.json` + `MAJOR_CAPABILITY_SERVER_SIDE_GEMINI_API` in `metadata.json`. No `import` under `apps/` or `packages/`. Do not add Gemini calls unless a phase introduces them.
- `express` in root `package.json`. Runtime HTTP is Fastify only (`apps/plateflow-api/src/infrastructure/http/app.ts`).

## Data Storage

**Databases:**

- PostgreSQL (Supabase-hosted or local)
  - Connection: `DATABASE_URL`. Local fallback in `packages/database/src/client.ts`: `postgresql://postgres:postgres@localhost:5432/postgres`.
  - Client: `drizzle(getPool(), { schema })` exported as `db` from `packages/database/src/index.ts`. Repositories: `apps/plateflow-api/src/infrastructure/database/DrizzlePlateRepository.ts`, `DrizzleRedirectRepository.ts`, `DrizzleTemplateRepository.ts`, `DrizzleAnalyticsRepository.ts`.
  - Tables (`packages/database/src/schema/index.ts`): `templates`, `redirects` (unique `slug`, `jsonb` metadata), `plates`, `analytics`.
  - Migrations: `packages/database/src/migrate.ts` (connectivity + seed + count, not SQL migrations). Schema push/generate: `drizzle-kit` scripts in `packages/database/package.json`. Config: `packages/database/drizzle.config.ts`.

**File Storage:**

- Local / inline only. Template artwork lives as `text` data URIs in `templates.background_url`. Composed PNGs and ZIPs are generated in the browser (`imageComposerService.ts`) and downloaded — not uploaded to object storage. No S3, GCS, or Supabase Storage client.

**Caching:**

- None (no Redis/Memcached). In-process `pg.Pool` singleton in `packages/database/src/client.ts` (`max: 10`). Frontend caches API payloads in `localStorage` keys in `apps/plateflow-app/src/services/storageService.ts` (`nfc_qr_*_v2`).

## Authentication & Identity

**Auth Provider:**

- Custom single-admin credentials (not Supabase Auth, not JWT).
  - Implementation: `POST /api/auth/login` compares body to `ADMIN_EMAIL` / `ADMIN_PASSWORD` (defaults `admin@plateflow.com` / `plateflow2026`) in `apps/plateflow-api/src/infrastructure/http/controllers/AuthController.ts`. Success token is `mock_token_admin_${Date.now()}`.
  - Session check: `GET /api/auth/me` accepts `Authorization: Bearer` or `x-auth-token` if the token starts with `mock_token_admin_` (`AuthController.ts`, `apps/plateflow-api/src/infrastructure/http/middleware/authMiddleware.ts`).
  - Protected writes: `requireAuth` on plate batch/update/delete, redirect update, template create/delete (`plateRoutes.ts`, `redirectRoutes.ts`, `templateRoutes.ts`).
  - Client: `StorageService.login` / `verifyAuth` in `apps/plateflow-app/src/services/storageService.ts` stores token + user in `localStorage`. UI copy mentions “Supabase” (`LoginModal.tsx`, `App.tsx`) but the login path is `/api/auth/login`, not `@supabase/supabase-js`.
  - `JWT_SECRET` in `turbo.json` is unused. Do not implement JWT without replacing the mock-token contract.

## Monitoring & Observability

**Error Tracking:**

- None (no Sentry, Datadog, or OpenTelemetry package).

**Logs:**

- Fastify built-in logger when `NODE_ENV !== 'test'` (`apps/plateflow-api/src/infrastructure/http/app.ts`).
- `console.log` / `console.warn` / `console.error` for boot (`server.ts`), seed (`app.ts`), DB pool errors (`packages/database/src/client.ts` — messages sanitized by `sanitizeErrorMessage()`), redirect failures (`publicRedirectRoutes.ts`), analytics increment (`ResolveRedirectUseCase.ts`), Vercel handler (`apps/plateflow-api/src/server.ts`).
- Health: `GET /api/health` runs `db.execute('SELECT 1')` and returns `{ status, database, timestamp }` or HTTP 503 (`app.ts`).

## CI/CD & Deployment

**Hosting:**

- Vercel. `vercel.json` rewrites `/api/(.*)` and `/r/(.*)` to `/api/index?__route=...`. Serverless entry `api/index.ts` default-exports the Fastify inject handler from `apps/plateflow-api/dist/server.js`. SPA assets from `dist/` (`package.json` `build` copies `apps/plateflow-app/dist/*`). Platform injects `VERCEL` so processes skip `listen()`.

**CI Pipeline:**

- None. No `.github/workflows`. No Dockerfile.

## Environment Configuration

**Required env vars:**

- `DATABASE_URL` — Postgres (Supabase pooler or local). Used by `packages/database/src/client.ts` and seed in `apps/plateflow-api/src/infrastructure/http/app.ts`.
- `ADMIN_EMAIL` — admin login identity (`AuthController.ts`).
- `ADMIN_PASSWORD` — admin login secret (`AuthController.ts`).
- `PORT` — HTTP listen port, default `3005` (`server.ts`).
- `NODE_ENV` — `production` | `test` | unset (`server.ts`, `app.ts`).
- `VERCEL` — set by Vercel; skip listen + dotenv (`server.ts`, `apps/plateflow-api/src/server.ts`, `packages/database/src/client.ts`).
- `DISABLE_HMR` — optional Vite flag (`apps/plateflow-app/vite.config.ts`).
- `JWT_SECRET` — listed in `turbo.json` only; not read by application code.

**Secrets location:**

- Local `.env` at repo root (loaded by `dotenv` in `packages/database/src/client.ts`). `.gitignore` ignores `.env*`. `.env.example` file present as the committed template — do not commit real `.env` values. Vercel project env for production. Never put secrets in `metadata.json` or client bundles.

## Webhooks & Callbacks

**Incoming:**

- None. No webhook routes. Public surface is:
  - `GET /r/:slug` and `GET /api/redirects/:slug/resolve` — QR/NFC landing (`publicRedirectRoutes.ts`).
  - REST under `/api/auth`, `/api/plates`, `/api/redirects`, `/api/templates`, `/api/analytics`, `/api/health` (`app.ts` + route files).
  - `POST /api/analytics` is called from `storageService.ts` `recordClick()` but **no POST handler exists** on `analyticsRoutes.ts` (GET only). Server-side click logging happens inside `ResolveRedirectUseCase.ts` on `/r/:slug`.

**Outgoing:**

- HTTP `307` redirects to customer destinations, `https://wa.me/...`, or `https://instagram.com/...` (`publicRedirectRoutes.ts`).
- Browser `fetch` from the SPA to same-origin `/api/*` (`apps/plateflow-app/src/services/storageService.ts`).
- No outbound webhook/callback clients.
